# Sitio de recetas — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un sitio en español que busca recetas en TheMealDB, muestra el paso a paso y guarda favoritas en PostgreSQL.

**Architecture:** FastAPI expone un contrato normalizado. Un protocolo `RecetasProvider` aísla a TheMealDB; un caché en memoria envuelve ese proveedor. SQLAlchemy 2 guarda solo favoritos. Next.js (App Router) consume el backend desde Server Components y deja comentarios donde se pegará la UI de v0.

**Tech Stack:** Python 3.12, FastAPI, Pydantic v2, httpx, SQLAlchemy 2, PostgreSQL 17, pytest, Next.js App Router, Tailwind, shadcn/ui.

**Spec:** `docs/superpowers/specs/2026-10-08-recetas-design.md`

## Global Constraints

- Carpetas exactas: `/backend` y `/frontend`.
- Backend: `routers/`, `services/`, `schemas/`, `models/`, `core/`.
- Proveedor TheMealDB detrás de `services/providers/`. No importar TheMealDB desde los routers.
- Clave y URLs solo en `.env`. Existe `.env.example`. Ninguna clave en el código.
- CORS: origen `http://localhost:3000`.
- Docs en `/docs`.
- Tests con pytest y la API externa simulada. Un test por endpoint.
- No instalar paquetes globales. No borrar datos. No usar las bases `icomers` ni `bd_icmers`.
- Crear la base `recetas` solo después de que este plan esté confirmado.
- Fases: 1 backend y tests, 2 estructura del frontend, 3 conexión con v0. La fase 3 no empieza sin los componentes.
- Consultar Context7 al implementar: FastAPI `/websites/fastapi_tiangolo`, SQLAlchemy `/websites/sqlalchemy_en_20_orm`, Next.js `/websites/nextjs`.
- Aplicar `api-design-principles`, `error-handling-patterns`, `postgresql-table-design`. En el frontend, `frontend-design` y `vercel-react-best-practices` sobre la estructura, no inventando la UI de v0.

## Review Focus

- Instrucciones de TheMealDB vienen en un solo texto, a veces numeradas y a veces en párrafos: el detalle debe devolver pasos limpios y en orden.
- `buscar`, `ingredientes` y `aleatoria` no pueden ser capturados por `/{id}`.
- Varios ingredientes se intersectan; un ingrediente sin coincidencias deja la intersección vacía, no la unión.
- Un favorito repetido no crea otra fila.
- Si TheMealDB falla al listar favoritos, la lista guardada sigue respondiendo.
